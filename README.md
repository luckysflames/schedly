# Schedly

Мобильное приложение для студентов ДГТУ: расписание занятий, данные профиля и цифровые студенческие сервисы — в одном интерфейсе.

Schedly помогает быстро посмотреть занятия группы или преподавателя, сравнить расписания и сохранить персональные настройки. Для авторизованных пользователей доступны данные профиля, студенческий билет и QR-код пропуска.

## Возможности

- **Расписание группы:** просмотр по дням, неделям и месяцам, переход к текущей дате и обновление данных.
- **Расписание преподавателя:** поиск преподавателя и просмотр его занятий.
- **Сравнение расписаний:** сопоставление расписаний двух групп или расписания группы с расписанием преподавателя.
- **Настройка расписания:** избранные группы и преподаватели, фильтр предметов, пользовательские цвета занятий.
- **Изменения расписания:** определение обновлений и, при включённой настройке, подсветка новых и изменённых занятий.
- **Профиль студента:** вход в аккаунт ДГТУ, просмотр личных и университетских данных.
- **Студенческие сервисы:** просмотр студенческого билета и получение QR-кода пропуска.
- **Персонализация:** темы оформления, сезонные анимации и настройки поведения приложения.
- **Работа с сохранёнными данными:** расписание, настройки и избранное сохраняются локально; каталоги групп и преподавателей хранятся в SQLite и поддерживают поиск с постраничной загрузкой.

## Технологии

- React Native 0.83 и React 19
- Expo SDK 55 и EAS Build / Update
- React Navigation 7
- Zustand для состояния и персистентного хранения
- SQLite (`react-native-quick-sqlite`) для локальных данных
- Expo SecureStore для сохранения учётных данных
- React Native Skia и Reanimated для анимаций и визуальных эффектов
- Lucide React Native для иконок

## Источник данных

Приложение обращается к API ДГТУ (`https://edu.donstu.ru/api`) за расписанием, каталогами, данными профиля и студенческими сервисами. Отдельный сервер приложения в этом репозитории не предусмотрен. Доступность актуальных данных зависит от работы API и подключения к интернету; при недоступности расписания приложение может показать сохранённую версию для выбранной группы.

## Запуск и сборка

### Требования

- Node.js и npm
- Android Studio с установленным Android SDK для локального запуска на Android
- Учётная запись Expo/EAS для облачных сборок и публикации обновлений

### Установка зависимостей

```bash
npm install
```

### Запуск

```bash
npm start
```

Для Android используйте нативный запуск — проект включает SQLite-модуль, которому нужна нативная сборка:

```bash
npm run android
```

### Android-сборка через EAS

```bash
npm run build
```

Команда собирает Android APK с профилем `preview`. Конфигурация профилей находится в [`eas.json`](./eas.json).

## Структура проекта

```text
components/   Переиспользуемые компоненты, экраны, модальные окна и эффекты
constants/    Общие константы интерфейса
hooks/        Логика экранов, расписания и темы
screens/      Главные экраны приложения
store/        Глобальное состояние приложения (Zustand)
theme/        Темы оформления
utils/        API, SQLite, форматирование и обработка расписания
assets/       Иконки и графические ресурсы
```

## Для портфолио

В проекте реализованы интеграция с внешним API, авторизация с безопасным хранением учётных данных, локальная персистентность на SQLite, адаптация входящих данных расписания и интерактивные сценарии сравнения и фильтрации. Интерфейс разделён на экраны и переиспользуемые компоненты, а состояние и бизнес-логика вынесены в Zustand store и пользовательские хуки.
